# 水印相机项目运行说明

## 前提条件

1. 安装最新版本的Android Studio（推荐2023.1.1或更高版本）
2. 安装Android SDK 24-35（Android 8.0 - Android 15）
3. 配置JDK 17或更高版本
4. 确保有稳定的网络连接用于下载依赖

## 导入项目

1. 打开Android Studio
2. 点击 "Open an Existing Project"
3. 选择项目根目录 "d:\projects\水印相机"
4. 等待Android Studio同步项目和下载依赖（首次同步可能需要几分钟）

## 运行项目

### 使用模拟器
1. 打开AVD Manager（Tools > Device Manager）
2. 创建一个新的虚拟设备（推荐Pixel 6，API 33-35）
3. 启动模拟器
4. 点击Android Studio工具栏上的 "Run" 按钮或使用快捷键 Shift+F10

### 使用真机
1. 开启手机的开发者选项和USB调试
2. 使用USB线连接手机到电脑
3. 在手机上允许USB调试
4. 点击Android Studio工具栏上的 "Run" 按钮
5. 在弹出的部署对话框中选择您的设备
6. 等待应用安装并启动

## 权限授予

首次运行应用时，系统会请求以下权限，请务必授予：

- **相机权限**：用于拍照功能
- **位置权限**：用于获取地理位置信息添加到水印
- **存储权限**：用于保存照片到相册

### 权限说明
- Android 8.0-12：需要相机、位置、存储读写权限
- Android 13+：需要相机、位置、媒体图片读取权限

## 功能使用指南

### 主界面
应用启动后，您将看到现代化的相机预览界面：

- **顶部工具栏**：
  - 左侧：设置按钮（进入设置页面）
  - 右侧：闪光灯按钮（切换关闭/开启/自动模式）

- **底部控制区**：
  - 左侧：图库按钮（从相册选择图片）
  - 中间：拍照按钮（带呼吸动画效果）
  - 右侧：最近拍摄照片预览（点击可查看大图）

### 拍照操作
1. 对准要拍摄的物体
2. 可以点击屏幕任意位置进行对焦（显示对焦框动画）
3. 使用双指缩放调整画面大小
4. 点击底部中央的白色圆形拍照按钮拍摄照片
5. 拍摄的照片将自动保存到相册，并在右下角显示水印

### 水印内容
拍摄的照片会自动添加以下水印信息（可在设置中自定义）：
- 拍摄日期时间
- 经度和纬度
- 海拔高度（如启用）
- 具体地址（如启用）
- 自定义文字（如设置）

### 设置页面
点击顶部设置按钮进入设置页面，可以配置：
- 水印位置：底部、顶部、左侧、右侧
- 文字大小：调整水印文字大小
- 文字颜色：选择水印文字颜色
- 背景透明度：调整水印背景透明度
- 显示选项：开关日期时间、位置、地址、海拔显示
- 图片质量：调整保存图片的质量（70-95）
- 自定义文字：添加个性化水印文字

### 照片历史
- 点击最近拍摄照片预览可查看大图
- 在设置中可以查看所有拍摄历史
- 支持删除和分享照片

## 界面特性

### 动画效果
- **入场动画**：工具栏从上下滑入，流畅自然
- **按钮动画**：所有按钮都有点击缩放反馈
- **拍照按钮**：呼吸动画提示用户操作
- **对焦框**：点击后显示发光效果的对焦动画
- **拍照成功**：闪光效果和照片预览缩放动画

### 视觉设计
- 深色主题背景，护眼且专业
- 毛玻璃效果工具栏，现代感强
- 青绿色强调色，清新醒目
- 圆角设计，界面柔和

## 注意事项

1. **位置信息**：
   - 确保设备已开启定位服务（GPS）
   - 首次获取位置可能需要几秒钟
   - 室内环境可能无法获取精确位置

2. **海拔信息**：
   - 需要网络连接，通过Open Elevation API获取
   - 部分偏远地区可能无法获取海拔数据

3. **地址信息**：
   - 使用Android系统Geocoder解析
   - 需要网络连接
   - 部分位置可能无法解析出具体地址

4. **存储**：
   - 照片默认保存到系统相册的 "Pictures/WatermarkCamera" 文件夹
   - 同时保存在应用私有目录中供历史记录查看
   - Android 13+ 遵循分区存储机制

5. **性能**：
   - 应用已启用代码压缩和资源优化
   - Release版本会自动移除日志输出
   - 使用协程进行异步处理，避免卡顿

## 排错指南

### 同步Gradle失败
1. 检查网络连接，确保可以访问Google和Maven Central仓库
2. 尝试使用代理或切换网络环境
3. 清除Gradle缓存：File > Invalidate Caches / Restart

### 编译失败
1. 检查是否安装了正确版本的Android SDK（24-35）
2. 检查JDK版本是否为17或更高
3. 检查gradle/libs.versions.toml中的依赖版本是否兼容

### 应用崩溃
1. 检查Logcat中的错误信息
2. 确认所有权限已正确授予
3. 检查设备是否有足够的存储空间
4. 尝试清除应用数据后重新运行

### 相机无法启动
1. 确认相机权限已授予
2. 检查是否有其他应用正在使用相机
3. 尝试重启设备

### 位置信息获取失败
1. 确认位置权限已授予
2. 确认设备定位服务已开启
3. 尝试到室外开阔地带获取GPS信号
4. 检查网络连接是否正常
